# mia

A voice agent that joins your Google Meet calls as a live participant,
listens for a wake word, and acts immediately on spoken commands by calling
real Google APIs — starting with blocking time on your calendar, mid-meeting.

It's not a notetaker: there's no transcript or summary deliverable. Speech
is only ever used transiently to detect the wake word and capture the
command that follows.

Active development and the full design spec live on the [`mia`](../../tree/mia)
branch.
